プライバシーポリシー

制定日：2026年11月1日　改定日：2026年11月3日

酒GO!!伝説（以下「本アプリ」）で扱う情報と、その扱い方についての説明です。本アプリはアカウント登録やログインがなく、遊ぶために名前やメールアドレスなどの個人情報を運営者に送っていただく必要はありません。

1端末の中だけに保存する情報

遊ぶために、次の情報をお使いの端末（ブラウザの保存領域）に保存します。これらは端末の外へは送られず、運営者が見ることもできません。

  • 前回入力したプレイヤー名、人数、ラウンド数（次に遊ぶときの入力を省くため）
  • カードの編集内容（使うカードのオン・オフ、追加や変更したカード）
  • 遊んでいる途中のゲームの状態（「続きから再開」のため。最後に遊んでから12時間たつと消えます）
  • 20歳以上であることを確認したこと（次から確認の画面を出さないため）
  • 「あそびの記録」（遊んだ回数・日数・時間、引いたカードやミニゲームの回数など。プレイヤー名は含みません）
  • 効果音・BGM・遊び方ガイドなどの設定

「あそびの記録」は、その画面の「記録をリセット」で消せます。すべての情報は、ブラウザの設定でこのサイトのデータを削除するか、ホーム画面に追加したアプリを削除すると消えます。

2外部に送られる情報

本アプリを使うと、次の事業者に情報が送られます。

GitHub Pages（GitHub, Inc.）

目的
本アプリの配信
送られる情報
IPアドレス、ブラウザの種類、アクセス日時など、ウェブページを開くときに通常送られる情報

GitHub は、サイトの安全を守るために訪問者のIPアドレスを記録することがあります。詳しくは GitHub のプライバシーに関する声明 をご覧ください。

Google Fonts（Google LLC）

目的
画面の文字（フォント）の表示
送られる情報
IPアドレス、ブラウザの種類、表示するフォントの種類など

詳しくは Google プライバシーポリシー をご覧ください。

利用状況の集計（運営者のサーバー。Cloudflare, Inc. のサービスを利用）

対象
このサイト（shugodensetsu.github.io）で配信している本アプリ。ブラウザで開いた場合も、ホーム画面に追加した場合も同じです。集計しているあいだは、「あそびの記録」画面に案内とオン・オフのスイッチが表示されます。
目的
どの機能がどれくらい使われているかを知り、本アプリを改善するため
送るタイミング
ゲームを始めたときと、終えたとき（途中でアプリを閉じたり別のアプリに切り替えたりしたときを含む）。「友達に教える」「ホーム画面に追加」のボタンを使ったとき
送られる情報
モード（カード・ミニゲーム）、カードの出かた（バランス・にぎやか）、人数、ラウンド数、ターン数、記録した杯数の合計、遊んだ時間、最後まで遊んだかどうか、出た組み込みカードの番号と回数、追加や変更したカードを引いた回数、遊んだミニゲームと使った特殊ルールの種類と回数、ホーム画面から開いたかどうか、スマホかタブレットか、その端末で何回目のゲームか、ゲームごとに作る使い捨ての番号、ボタンの種類
送らない情報
プレイヤー名、カードの文章、端末や利用者を見分ける識別子（Cookie などは使いません）
保存のしかた
運営者のデータベース（Cloudflare D1）に保存します。通信のしくみ上、IPアドレスとブラウザの種類もサーバーに届きますが、データベースには保存しません（短時間に大量の送信がないかを確かめるため、一時的に使うだけです）。

送信を止めたいときは、「あそびの記録」画面のスイッチを「集計に協力しない」にしてください。Cloudflare は、サービスの運用と安全のためにアクセスの記録を扱うことがあります。詳しくは Cloudflare のプライバシーポリシー をご覧ください。

3集計した情報の使い方

利用状況の集計で集めた情報は、個人を特定しない統計として、本アプリの改善だけに使います。運営者は利用者の個人情報を持っていないため、第三者に提供することはありません。

4広告

現在、本アプリに広告はありません。広告を入れるときは、このポリシーを改定して内容をお知らせします。

5年齢について

本アプリは、20歳以上の方が飲み会で使うことを想定しています。20歳未満の飲酒は法律で禁止されています。飲めない人はソフトドリンクで参加でき、無理に飲ませることはやめましょう。

6このポリシーの変更

内容を変更するときは、このページを更新し、ページ上部の日付を改めます。
