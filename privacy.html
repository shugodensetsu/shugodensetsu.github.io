プライバシーポリシー

制定日：2026年11月1日　改定日：2026年11月18日

DON!!でんパーティー（以下「本アプリ」）で扱う情報と、その扱い方についての説明です。本アプリはアカウント登録やログインがなく、遊ぶために名前やメールアドレスなどの個人情報を運営者に送っていただく必要はありません。

1端末の中だけに保存する情報

遊ぶために、次の情報をお使いの端末（ブラウザの保存領域）に保存します。これらは端末の外へは送られず、運営者が見ることもできません。

  • 前回入力したプレイヤー名、人数、ラウンド数（次に遊ぶときの入力を省くため）
  • カードの編集内容（使うカードのオン・オフ、追加や変更したカード）
  • 遊んでいる途中のゲームの状態（「続きから再開」のため。最後に遊んでから12時間たつと消えます）
  • 「あそびの記録」（遊んだ回数・日数・時間、引いたカードやミニゲームの回数など。プレイヤー名は含みません）
  • 効果音・BGM・遊び方ガイドなどの設定

「あそびの記録」は、その画面の「記録をリセット」で消せます。すべての情報は、ブラウザの設定でこのサイトのデータを削除するか、ホーム画面に追加したアプリを削除すると消えます。

2外部に送られる情報

本アプリを使うと、次の事業者に情報が送られます。

GitHub Pages（GitHub, Inc.）

目的
本アプリの配信
送られる情報
IPアドレス、ブラウザの種類、アクセス日時など、ウェブページを開くときに通常送られる情報

GitHub は、サイトの安全を守るために訪問者のIPアドレスを記録することがあります。詳しくは GitHub のプライバシーに関する声明 をご覧ください。

Google Fonts（Google LLC）

目的
画面の文字（フォント）の表示
送られる情報
IPアドレス、ブラウザの種類、表示するフォントの種類など

詳しくは Google プライバシーポリシー をご覧ください。

利用状況の集計（運営者のサーバー。Cloudflare, Inc. のサービスを利用）

対象
このサイト（shugodensetsu.github.io）で配信している本アプリ。ブラウザで開いた場合も、ホーム画面に追加した場合も同じです。集計しているあいだは、「あそびの記録」画面に案内とオン・オフのスイッチが表示されます。
目的
どの機能がどれくらい使われているかを知り、本アプリを改善するため
送るタイミング
ゲームを始めたときと、終えたとき（途中でアプリを閉じたり別のアプリに切り替えたりしたときを含む）。「友達に教える」「ホーム画面に追加」「結果を画像でシェア」のボタンを使ったとき。プレミアムの画面を開いたときと、料金プランを選んだとき。電波がなくて送れなかったものは端末に最大7日間とっておき、つながったときに送ります
送られる情報
モード（カード・ミニゲーム・暴露トーク・ニセ画伯・返信選手権・しれっとミッション・ウソかホントか）、カードの出かた（バランス・にぎやか）、暴露トークの質問のジャンル、ほかのモードで選んだお題の種類（むずかしさ・ジャンルなど）、人数、ラウンド数、ターン数、記録したDONの合計、遊んだ時間、最後まで遊んだかどうか、出た組み込みカードの番号と回数、追加や変更したカードを引いた回数、遊んだミニゲームと使った特殊ルールの種類と回数、暴露トークで出た質問の番号と回数、ホーム画面から開いたかどうか、スマホかタブレットか、その端末で何回目のゲームか、ゲームごとに作る使い捨ての番号、ボタンの種類、プレミアムの画面を開いた場所と選んだプランの種類、運営者のテスト用の端末から送られたものかどうかの印（テスト用の端末からは、それまでの分を見分けるための日ごとの遊んだ回数も）
送らない情報
プレイヤー名、カードの文章、返信選手権で入力した文章、ニセ画伯で描いた絵、端末や利用者を見分ける識別子（Cookie などは使いません）
保存のしかた
運営者のデータベース（Cloudflare D1）に保存します。通信のしくみ上、IPアドレスとブラウザの種類もサーバーに届きますが、データベースには保存しません（短時間に大量の送信がないかを確かめるため、一時的に使うだけです）。

送信を止めたいときは、「あそびの記録」画面のスイッチを「集計に協力しない」にしてください。Cloudflare は、サービスの運用と安全のためにアクセスの記録を扱うことがあります。詳しくは Cloudflare のプライバシーポリシー をご覧ください。

プレミアムのお支払い（Stripe, Inc. ／ 運営者のサーバー）

対象
プレミアムを購入するとき、アプリを開いたときや画面に戻ったとき（プレミアムの期限と、この端末でプレミアムが有効かを確かめます）、復元コードで引き継ぐとき、解約・お支払い方法を変えるとき
Stripe に送られる情報
お支払いの画面（Stripe のページ）で入力したメールアドレス、カードの情報、お支払いに必要な情報。カードの番号などを運営者が受け取ることはありません
運営者のサーバーに保存する情報
復元コード（元に戻せない形に変換したもの）、選んだプラン、プレミアムの期限、解約の予定があるかどうか、Stripe でのお支払いを見分ける番号（Stripe の顧客・購読・お支払いの番号）、プレミアムが有効な端末の鍵（購入や引き継ぎのたびにサーバーが作る意味のない乱数。サーバーには元に戻せない形に変換したものだけを保存）と、その端末が有効になった日時、以前にその購入で使われていた端末の鍵（同じく変換したもの。引き継いだ端末が引き継ぎ直せないようにするため）。名前・メールアドレス・カードの情報・端末の機種などは保存しません
端末に保存する情報
復元コード、プラン、期限、プレミアムが有効な端末の鍵、最後に確かめた日時、以前にその端末が持っていた鍵（最大10件）
目的
プレミアムを使えるようにするため、1つの購入で同時にプレミアムを使える端末を1台にするため、引き継ぎ・解約・お問い合わせに対応するため

Stripe での情報の扱いは Stripe のプライバシーポリシー をご覧ください。

みんなのスマホで参加（運営者のサーバー ／ Cloudflare, Inc.）

対象
プレミアムの方が「参加」の部屋を作ったとき、友だちが合言葉やQRコードでその部屋に参加したとき
送られる情報
部屋の合言葉、その部屋で遊ぶために親のスマホと参加した人のスマホのあいだでやりとりする内容（ゲームで使う名前、お題・ミッション、入力した返信、描いた線、投票など）。部屋を作るときは、プレミアムが有効かを確かめるため、復元コードとプレミアムが有効な端末の鍵を送ります
運営者のサーバーに保存する情報
部屋が開いているあいだだけ、部屋の合言葉、親と参加した人を見分ける鍵（意味のない乱数を元に戻せない形に変換したもの）、参加を受け付けているかどうか。やりとりする内容は中継するだけで保存しません。部屋は親が終わりにしたとき、または作ってから6時間で消えます
端末に保存する情報
部屋の合言葉と鍵（部屋に戻るため。最大6時間）
目的
それぞれのスマホで同じゲームに参加できるようにするため

3集計した情報の使い方

利用状況の集計で集めた情報は、個人を特定しない統計として、本アプリの改善だけに使います。運営者は利用者の個人情報を持っていないため、第三者に提供することはありません。

4広告

現在、本アプリに広告はありません。広告を入れるときは、このポリシーを改定して内容をお知らせします。

5遊び方について

本アプリは、年齢を問わず遊べるパーティーゲームです。罰ゲーム（DON）の中身は参加者みんなで決め、嫌がる人に無理強いしないでください。
