# 酒GO!!伝説

飲み会を盛り上げるカードゲーム。引いたが最後！ 天国か、地獄か。
スマホ1台を2〜8人で回して遊びます。

**遊ぶ：** https://shugodensetsu.github.io/

## iPhoneのホーム画面に追加する

1. 上のURLを **Safari** で開く
2. 下の「共有」ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、全画面のアプリとして動きます

一度開けば、そのあとはオフラインでも遊べます。

## 使い方

- タイトルの「遊び方ガイド」、ゲーム中は右上の「？ 遊び方」から、アプリ内のガイドが開きます（はじめに／記録のしかた／特殊ルール／カードと手札／ミニゲーム／その他）。
- はじめてのゲームでは、1ターン目に「次に何を押せばいいか」の案内が出ます。メンバー登録画面のチェックでON/OFFできます。
- 飲む人が決まっているカード（「左隣は1杯」「全員でグイ」など）は、カードを閉じると自動で記録されます。指名やジャンケンのカードは「誰が飲む？」画面で飲む人をタップするだけ。ミニゲームで負けた人も自動で記録されます。
- 飲む人が記録されると「特殊ルールを使う？」と聞かれます。倍倍FIGHT！・天国と地獄・券を使うか、素直に飲むかを選ぶだけ。何人もいるときは使う人を選び、2人以上なら順番はランダム。
- 続くルール（継続カード）は画面上の「継続中」の帯に表示。違反した人がいたら帯をタップして選ぶだけで記録できます。インシュメイトはどちらかが飲むと、もう片方にも自動で記録されます。
- チンチロ・サイコロ・トランプ・インディアンポーカー・ダーツのカードは「アプリで〇〇！」でアプリの中で遊べます（負けた人は自動で記録）。

## 補足

- カード編集で保存した内容は、その端末の中にだけ保存されます（端末ごとに別々）。
- 「最初のカードに戻す」で、はじめのカードに戻せます。
- 20歳未満の飲酒は法律で禁止されています。飲めない人はソフトドリンクで参加OK。無理に飲ませるのはやめましょう。

## 開発メモ

- ゲーム本体のソースは `src/` にあります（`part-*.js` と `deck-template.html`、はじめのカードは `deck.json`）。
- `node src/build-app.js` で、ルートの `index.html` / `manifest.webmanifest` / `sw.js` を作り直します。
- アイコンは `node src/icon.js` で作り直せます（Playwright と日本語フォントが必要）。
- GitHub Pages（main ブランチのルート）で公開しています。
